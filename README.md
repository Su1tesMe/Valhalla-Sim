# Welcome to Valhalla-Sim Version 0
## Main Goal:
- Create a game where you as a player fight for survival in a world with monsters and NPCs that also relies on a soul system that may change how opponents behave.

## Goals to Complete Main Goal:
- Create a system that can spawn in NPCs and Monsters
  - They should have personal_data like names, health, damage (maybe), and soul-type
- Create a world that the player can move around in
  - Preferably with some sort of visual, but early builds are allowed to be text-based
  - NPCs and Monsters should be able to move around in the world as well
- Create a functioning combat system
  - Monsters and NPCs should be able to fight back
  - Should include either Leveling System or Gear Hierarchy to improve skills
    - NPCS should also have this ability, but not monsters
- Create a soul mechanic that can affect stats and abilities
  - Soul percentage is also tied to revival system
  - NPCs can drop souls if they do not revive
- Create a mechanic where revival is unpredictable
  - First revive is guaranteed, with future revives less likely
  - Absorbing souls can boost the chances of revival
